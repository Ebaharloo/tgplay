# DEV: web UI, Milestone 1 (2026-11-13)

The window is now a local web app: Python serves the same data the Qt window
shows, the Astryx/React bundle renders it. Qt is untouched and still the
default (`./tgplay`); the web window is `./tgplay --web`.

## What exists

**`tp/web/server.py`** - `AppState` + `Handler` on a stdlib
`ThreadingHTTPServer` (default `127.0.0.1:8799`, `TPLAY_WEB_PORT` overrides).
Every long job runs on a worker thread; handlers answer with the current
snapshot at once.

| endpoint | what it does |
|---|---|
| `GET /api/state` | one snapshot: `lights`, `rails{continue,recent}`, `feed`, `history`, `session`, `search`, `opts{fields,opts,mpv}`, `rails_settings`, `status{message,loading,playing}`, `log` |
| `GET /api/events` | SSE, log tail in one burst (`retry: 2000`, EventSource reconnects) |
| `POST /api/search {q}` | `ShowFinder.find` on a worker |
| `POST /api/open {src,url}` | `SessionLoader` (same path as `gui_all.load_target`); `src` may be empty for a pasted link (`cli_all.route`) |
| `POST /api/play {eps[],fields?,opts,mpv}` | one video at a time, like the Qt window |
| `POST /api/stop` | `Session.stop()` |
| `POST /api/options {fields,opts,mpv}` | normalizes through `tp.options.form_result` (same model the Qt form uses) |
| `POST /api/settings {rails}` | `recent.save_rails` -> `ui.json`, then reloads the library |
| anything else | `web/dist` (SPA fallback to `index.html`); a "bundle missing, run `cd web && npm run build`" page when dist is absent |

Errors are JSON: 400 `{"error": "..."}` for user mistakes (no session, bad
JSON, bad episode number, blank search), 500 only for real bugs (and logged via
`tp.log`). Every worker failure lands in `status.message` instead of vanishing.

Reused as-is: `library.overview`, `continuewatch.ContinueWatching.items`,
`recent.RecentlyAired.items`, `recent.load_rails/save_rails`,
`simkl_extra.SimklExtra`, `session.SessionLoader/open_session`, `finder.ShowFinder`,
`options.form_fields/form_result`, `status.StatusProbe`, `log.SINK`.

**`tp/web/run.py`** - starts the server, opens `chromium --app=<url>` (falls
back to `chromium-browser`, `google-chrome`, `microsoft-edge`, then
`firefox --new-window`), stops the server when the window closes.

**`./tgplay --web`** - one branch added to the launcher; `./tgplay` still starts Qt.

**`web/`** - Vite + React 19 + Astryx 0.7.14, `node_modules` is a symlink to
`/home/user/node_modules` (no second copy). Only `vite` was added there;
`@vitejs/plugin-react` could not install (`ERESOLVE`: it wants `@babel/core@8`,
the Astryx CLI pins 7) and is not needed - Vite's built-in JSX transform covers
the build. Files: `index.html`, `vite.config.js`, `src/main.jsx`,
`src/app.jsx`, `src/api.js`, `src/styles.css`. Five slots + sidebar as in
PLAN-WEB.md; Astryx `Card/TabList/Tab/TextInput/Selector/CheckboxInput/Badge/
Button/DropdownMenu/Heading/Text/Theme`, dark mode.

**`tests/test_web.py`** - 6 hermetic cases (server on port 0, stubbed
library/session/finder, no network, no browser): state shape, search rows,
open/play/stop 400s then success, options round-trip equals `form_result`,
settings reach `ui.json` and the next state, SSE emits a `tp.log` line.

## How to run

```bash
cd /home/user/coding/python/tgplay
(cd web && npm run build)      # once, or after front-end edits
./tgplay --web                 # window + server, Ctrl+C / close window stops it
```

Server only (no window), for poking or a screenshot:

```bash
TPLAY_FAKE=1 .venv/bin/python -m tp.web.server        # fake data, no network
.venv/bin/python -m tp.web.server                     # real data
```

Front-end dev loop: `cd web && npm run dev` (proxies `/api` to :8799).

`web/shots/m1.png` - 1360x962, real bundle against `TPLAY_FAKE=1`.
Captured with Chromium under Xvfb:

```bash
TPLAY_FAKE=1 .venv/bin/python -m tp.web.server &
xvfb-run -a -s "-screen 0 1360x1000x24" bash -c '
  /home/user/.cache/ms-playwright/chromium-1234/chrome-linux64/chrome \
    --no-sandbox --disable-gpu --app=http://127.0.0.1:8799 \
    --window-size=1360,1000 --window-position=0,0 &
  sleep 10; import -window root web/shots/raw.png; kill %1'
magick web/shots/raw.png -crop 1360x962+0+38 +repage web/shots/m1.png
```

Headless `--screenshot --virtual-time-budget` does **not** work here: the page
polls `/api/state` every 1.5 s, virtual time never reaches idle, Chrome hangs.
The Xvfb window + `import -window root` route also drops Chrome's "for testing"
infobar by cropping 38 px.

Posters are initials-only on purpose: the fake rows carry no poster and there
is no network during the capture. A real poster URL renders in the same box.

## Deliberately not in M1

- Cast dialog, Simkl PIN login, calendar day filters beyond Recent, prefetch
  progress, mpv embedding, packaging, light-theme polish (PLAN-WEB.md list).
- No window split/resize (`ui.json window.split`): the sidebar is a fixed
  340 px column.
- Rail card click runs a search for that title; it does not auto-open the best
  hit (no silent pick among sources/seasons).
- Copy episode link needs a resolved stream (`provider.stream`), which M1 does
  not call; the menu item says "nothing to copy" until that lands.
- Right-click menus are per-row `⋯` DropdownMenus: Astryx anchors a menu to
  its trigger, not the pointer, so right-click only selects the row.
- `/api/settings` doubles as the refresh button (reloads the library); no
  extra `/api/refresh` endpoint.
- `gui_all._fetch_extra`'s ancestor filter is not reproduced (first 60 simkl
  ids win) - noted as `shortcut:` in `AppState._extra`.
